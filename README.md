# Foxey's Home Assistant Apps

A custom [Home Assistant App Store](https://contributors.home-assistant.io/apps/guides/repository/)
repository. Add it in Home Assistant under **Settings → Add-ons → Add-on Store →
⋮ → Repositories**:

```
https://github.com/foxey/home-assistant-apps
```

## Apps

- [`cert_sync`](cert_sync/) — syncs an ACME certificate from Redis directly
  into Home Assistant Core. See [cert-sync](https://github.com/foxey/cert-sync).
